FileLens Privacy Policy

Effective date: September 26, 2026

FileLens is a local-first Windows desktop application.

File contents

Log, text, CSV, TSV, JSONL, and Parquet data opened in FileLens is processed locally on the user's computer. FileLens does not upload the contents of those files to a FileLens-operated cloud processing service.

Local application data

FileLens may store settings, recent file paths, license state, and diagnostic logs in the user's local application-data directory. Diagnostic logging is intended to record application events and errors, not the contents of user data files.

Licensing

FileLens Pro may contact a licensing service over HTTPS to activate or validate a software license. Licensing requests may include a license key, application/device instance information, product identifiers, and license status. User file contents are not included in licensing requests.

Analytics

FileLens 1.0 does not include behavioral analytics or advertising telemetry.

Payments

Purchases will be processed by the payment provider displayed at checkout. FileLens does not directly collect or store payment-card numbers. When Stripe Managed Payments is used, Stripe handles the checkout and related payment processing as merchant of record for supported transactions.

Website hosting

This website may be hosted by a third-party static hosting provider. The hosting provider may process standard network information, such as IP addresses and request logs, for security and service operation.
